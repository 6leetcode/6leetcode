### [三个数的最大乘积](https://leetcode.cn/problems/maximum-product-of-three-numbers)

<p>给你一个整型数组 <code>nums</code>。</p>

<p>在数组中找出由三个数组成的 <strong>最大</strong> 乘积，并返回这个 <strong>最大</strong> 乘积。</p>

<p>&nbsp;</p>

<p><strong>示例 1：</strong></p>

<pre>
<strong>输入：</strong>nums = [1,2,-3]
<strong>输出：</strong>-6
<strong>解释：</strong>只有三个数字 1、2 和 -3，因此最大乘积是 1 * 2 * -3 = -6。</pre>

<p><strong>示例 2：</strong></p>

<pre>
<strong>输入：</strong>nums = [1,2,3,4]
<strong>输出：</strong>24
<strong>解释：</strong>最大的乘积来自三个最大的数字：2 * 3 * 4 = 24。
</pre>

<p><strong>示例 3：</strong></p>

<pre>
<strong>输入：</strong>nums = [-1,-2,-3]
<strong>输出：</strong>-6
<strong>解释：</strong>只有三个数字 -1、-2 和 -3，因此最大乘积是 (-1) * (-2) * (-3) = -6。
</pre>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>3 &lt;= nums.length &lt;=&nbsp;10<sup>4</sup></code></li>
	<li><code>-1000 &lt;= nums[i] &lt;= 1000</code></li>
</ul>
